# Amazon Clone 🛒

A frontend clone of the Amazon website built using **HTML5 and CSS3**. This project recreates the basic look and layout of an e-commerce website as a frontend development practice project, inspired by the Apna College CSS tutorial.

## 🌐 Project Overview

The Amazon Clone is a static e-commerce website interface designed to practice HTML and CSS concepts. It focuses on creating a familiar shopping website layout with navigation, product sections, banners, and categories.

## ✨ Features

- Amazon-inspired navigation bar.
- Search bar design.
- Product category sections.
- Promotional banners.
- Product display cards.
- Footer section.
- Structured and clean webpage layout.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/divyansh4589-sce/Amazon-Clone.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code.

## 🎯 Learning Objectives

- Understanding HTML page structure.
- Practicing CSS styling and layouts.
- Learning Flexbox and positioning.
- Working with images and backgrounds.
- Building a multi-section frontend website.

## 📌 Project Limitations

- This is a frontend-only project.
- No backend or database is connected.
- Shopping cart and payment functionality are not implemented.
- It is not affiliated with or endorsed by Amazon.
